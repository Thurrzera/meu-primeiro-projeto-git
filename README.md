\##Reflexão Final

1\. Qual a importância do Git para desenvolvimento de software?

O Git é capaz de gerenciar o controle de versão do código ao longo do tempo, permitindo visualizar o histórico ao registrar as mudanças feitas no projeto, voltar para uma versão anterior se algo nele quebrar e permite o trabalho em equipe.



2\. Como o uso de branches pode ajudar no trabalho em equipe?

O uso de branches ajuda o trabalho em equipe ao permitir que diferentes pessoas desenvolvam funções diferentes ao mesmo tempo sem atrapalhar o código principal ou o trabalho dos outros colegas.



3\. Por que é importante escrever mensagens de commit claras?

Escrever mensagens de commit de forma clara é essencial para explicar o motivo e o contexto de uma mudança no código, facilitando a manutenção do projeto a longo prazo



4\. Quando você usaria o arquivo .gitignore?

Sempre que fosse preciso impedir que o Git rastreie ou envie arquivos temporários, sensíveis ou simplesmente aqueles que forem gerados automaticamente e não são importantes para o repositório remoto



5\. Como o histórico de commits do seu repositório demonstra seu aprendizado?

O meu histórico de commits demonstra meu aprendizado pois registrou o processo do meu estudo, a criação e configuração de um novo repositório, uso de branches, merge, entender como surge um conflito e a resolvê-lo e .gitignore. Assim é possível observar o meu progresso no uso do Git
